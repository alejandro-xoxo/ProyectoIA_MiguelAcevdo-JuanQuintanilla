# Infusión – Código Cafeinado

Aplicación web responsiva (Mobile-First) diseñada para una cafetería corporativa de especialidad. El proyecto integra un catálogo de productos premium y un servicio innovador enfocado en el alto rendimiento técnico.

## 1. Arquitectura del Proyecto

El desarrollo sigue un paradigma de separación de responsabilidades y código limpio, utilizando el siguiente stack tecnológico[cite: 2]:
* **Estructura:** HTML5 Semántico[cite: 2].
* **Estilos:** CSS3 (Diseño Mobile-First estricto)[cite: 2].
* **Lógica:** JavaScript (Vanilla) sin dependencias externas[cite: 2].

## 2. Estructura de la Aplicación

La interfaz de usuario está dividida en las siguientes vistas requeridas[cite: 2]:
1. **Inicio (Hero):** Identidad de marca, eslogan y *Call to Action* principal[cite: 2].
2. **Nosotros:** Historia, misión, visión y valores corporativos[cite: 2].
3. **Catálogo:** Exhibición de 6 productos de especialidad con descripción, imagen y precio[cite: 2].
4. **Servicio Innovador:** Presentación de nuestro diferenciador estratégico (Coffee Match & Desk-Delivery) detallando mecánica y beneficios[cite: 2].
5. **Contacto:** Información de ubicación, canales digitales y formulario de interacción[cite: 2].

## 3. Servicio Innovador: "Coffee Match & Desk-Delivery"

Nuestro diferenciador estratégico[cite: 2] optimiza el consumo de café en entornos de desarrollo de software.
* **Propósito:** Emparejar la química del café premium con el estado neuro-cognitivo del usuario mediante un asistente interactivo[cite: 2].
* **Mecánica:** El usuario ingresa su estado de fatiga, actividad a realizar e intensidad deseada. El algoritmo en Vanilla JS procesa las variables y recomienda la extracción exacta[cite: 2].
* **Beneficios:** Eliminación de la fatiga por decisiones, mejora en la retención del foco intelectual y suministro logístico directo al escritorio (Desk-Delivery)[cite: 2].

*Para más detalles, consultar la documentación en `/docs`[cite: 2].*
